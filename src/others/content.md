# 内容文件

**内容文件（contents.json）** 提供了当前附加包的所有内容，它不是附加包正常运行所必需的。

它的主要作用是让市场中的文件能够被加密储存。不过，非加密的附加包也能够使用它。

## 创建内容文件

内容文件位于附加包根目录下的`contents.json`，下面是一个内容文件范例：

```json
{
  "content": [
    { "path": "texts/zh_CN.lang" },
    { "path": "contents.json" },
    { "path": "manifest.json" }
  ]
}
```

可以看到，`content`数组下每个元素的`path`属性储存了附加包文件的路径，而可选的`key`属性则用于解密附加包的内容。

## 自动生成

利用内容文件格式版本升级的特性，我们可以创建一个不包含任何文件路径的内容文件，让游戏引擎自动生成内容路径：

```json
{}
```

自动生成的原理是[^1]：

当该文件的版本不为 1 时，且触发了包验证、清单文件验证无误时，就会在验证完成清单后开启内容文件的验证：

- 先读取该文件内`content`下已填入的所有路径
- 然后扫描该附加包内所有文件，将真实存在在附加包内却不在该文件内列出的文件追加到该文件`content`数组末尾，并修正畸形的路径（
- 最后将`version`字段设置为1。
