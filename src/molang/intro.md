# Molang 简介

在数据驱动中，我们有时填入的属性不是一个定死的值——比如，我们希望实体被击败后随机掉落 1~4 点经验，而不是每次掉落固定的 1 点。

在这种情况下，已有的数据驱动接口不能很好地满足我们的灵活需求，而 JavaScript 又显得过于笨重，Molang 便应运而生。

> **Molang** 是一种基于表达式的简单语言，用于快速、数据驱动地在运行时计算数值，与游戏中的数值和系统直接连接。
> 
> 其设计目标是在保持高性能的同时，为动画等低级系统提供数据驱动的可变行为支持。

我们可以在几乎任何附加包的 JSON 文件中使用 Molang，短短几行便可以完成一个复杂且灵活的需求。
