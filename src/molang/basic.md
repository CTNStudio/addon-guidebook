# 语法基础
> [!IMPORTANT]
> 本节内容还在撰写中

Molang 使用一种简单的、类似 C 语言的语法。

它的表达式可以由值、数学运算、查询函数，或复杂的子表达式组成，以便实现更复杂的代码。

Molang 语句以分号（`;`）结尾，对于多行表达式而言分号是必须的，单行表达式可以省略分号。

## 变量

### 生命周期

变量可能有三种生命周期：

- 临时变量 （例如 temp.moo = 1;）根据 C 规则，适用于其定义的作用域。出于性能原因，其生命周期是全局的，适用于当前表达式执行，且可能返回其定义的最外作用域之外的有效值。复杂表达时要小心。我们将尽快添加内容错误以应对无效访问。
- 实体变量 （例如 variable.moo = 1;）在该实体的生命周期内将其值存储在该实体上。请注意，这些游戏目前未被保存，退出并重新加载世界会重新初始化。同样地，如果实体被消失，实体上的所有变量都会丢失。
- 实体变量 （例如 variable.moo = 1;）在该实体的生命周期内将其值存储在该实体上。请注意，这些游戏目前未被保存，退出并重新加载世界会重新初始化。同样地，如果实体被消失，实体上的所有变量都会丢失。

### 公共变量

实体的变量在一般情况下不能被其他实体访问。

要向其他实体开放只读访问变量，我们需要在拥有实体的资源定义中设置该变量的“public”设置，同时初始化该变量。

```json
{
  "format_version": "1.10.0",
  "minecraft:client_entity": {
    "description": {
      "scripts": {
        "variables": {
          "variable.oink": "public"
        },
        "initialize": [
          "variable.oink = 0;"
        ],
      },
    }
  }
}
```

## 别名
以下关键词别名可以在 Molang 中被使用：

- `context.xxx` -> `c.xxx`
- `query.moo`->`q.moo`
- `temp.moo` ->`t.moo`
- `variable.moo` -> `v.moo`
