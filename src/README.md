# 导论

或许，你已经尝试过 Minecraft 中一些知名的模组，比如暮色森林、魔法金属、农夫乐事等。

不论这些模组内容多么纷繁复杂，但是它们都有一个共同的特点：**都对游戏内容进行了修改，并在其之上添加了更多原版游戏没有的内容**——而对这些第三方内容的包容，也是 Minecraft 风靡至今的原因之一。

那这一切，又与附加包有什么关系呢？附加包又是什么呢？

## 什么是附加包？

关于这个问题，Mojang 在一篇 2016 的文章中做过说明：

> 对于新手来说，附加包基本上是一组文件，可以让改变游戏世界的运作方式。
> 
> 想要 50 英尺高的鸡？当然可以！想要创建一支穿着蓬蓬裙的猪灵大军？虽然很怪，但是也可以！[^1]

而关于这个问题，Minecraft Wiki 是这么表述的：

> **附加包（Add-on）** 允许玩家更改世界的纹理样貌、实体的模型、行为规则等，是实现 Minecraft 全版本自定义的坚实一步。
> 
> 行为包是一种用于改变实体的行为、掉落物、生成规则、物品合成配方与村民交易表等的附加包，其不仅可以改变现有内容，还可以创建新的实体、方块及物品；
>
> 而资源包属于附加包的一部分，和行为包并列，同时区分原版资源包与自定义资源包，原版资源包用于为游戏加入新内容而准备。[^2]

简而言之，附加包与 Java 版中的模组类似，都可以对 Minecraft 进行一系列的更改，我们可以认为附加包就是属于基岩版的「模组」。


## 附加包可以做什么？

在现代版本中，我们可以用附加包创建自定义的物品、实体、方块等，也可以添加自己的战利品表、配方，亦或是利用脚本对游戏事件进行监听！

然而由于诸多原因[^3]，附加包对游戏的自定义能力相较于模组还**有很大的缺陷**，例如：一些硬编码的物品、方块也无法通过附加包进行修改……**我们要对此做好心理准备。**

## 我们需要什么准备？

附加包的入门非常简单，一般而言，我们只需要在开始之前：

- 熟练掌握手头内电子设备的使用；
- 设备上有可以正常运行的 Minecraft 基岩版；
- 有足够的耐心与恒心；
- 有通过互联网查询资料的基本能力，以及使用机器翻译、*生成式人工智能*的基本能力。

如果你有以下能力，那么附加包的制作将非常简单：

- JSON 相关知识；
- JavaScript 基本知识。

准备好了吗，我们开始吧！
